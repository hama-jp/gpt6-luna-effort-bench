# 課題: 決算資料について質問に答える

いまいるディレクトリの `report.md` は、ある(架空の)企業の決算説明資料です。
このファイルだけを使って、下の質問に答えてください。単位・区分の組み替え・訂正に注意して読んでください。

答えは、いまいるディレクトリの `answers.json` に、キーが `q01` 〜 `q16` の JSON オブジェクトとして書いてください。値はすべて文字列です。

答えの書き方:
- 金額は、質問に指定がなければ百万円単位。数字だけで、カンマや単位は付けない。
  質問が小数第1位までを求めていなければ整数で答える。求めているときは小数第1位に四捨五入する(例 `"1234.5"`)。
- パーセントは数字だけで、小数第1位に四捨五入する(例 `"7.3"`)。
- 四半期は `"Q1"`・`"Q2"`・`"Q3"`・`"Q4"` のどれかで答える。
- 資料に答えるための情報が載っていない場合は `"記載なし"` と答える。

質問(正誤表で訂正された数字がある場合は、訂正後の数字を使う):

- q01: 2025年度通期の冷凍食品の売上高は?
- q02: 2025年度通期の冷凍食品の営業利益は?
- q03: 変更後の区分にそろえた場合、第2四半期の業務用の売上高は?
- q04: 変更後の区分にそろえた場合、通期の飲料の売上高は?
- q05: 第3四半期の海外事業の売上高を円に換算すると何百万円か(小数第1位まで)?
- q06: 海外事業を円換算して含めた、2025年度通期の全社売上高は何百万円か(小数第1位まで)?
- q07: 国内3セグメントの営業利益の通期合計は?
- q08: 2025年度通期の全社営業利益は?
- q09: 冷凍食品の売上高の前年度比の伸び率(%)は?
- q10: 冷凍食品の営業利益率(営業利益÷売上高)が最も高かった四半期は?
- q11: 期末の従業員数の合計(海外拠点を含む)は?

- q14: 第4四半期の全社費用のうち、特別な監査費用はいくらか?
