# 課題: 競技プログラミングの7問を解く

いまいるディレクトリの `problems/` に、競技プログラミングの問題が7問(`a.md` 〜 `g.md`)あります。
A から G に向かって難しくなります。できるだけ多くの問題を正しく解いてください。

## 提出のしかた

- 各問題の解答を `solutions/<問題の記号>.cpp` または `solutions/<問題の記号>.py` に置く
  (例: `solutions/a.py`、`solutions/f.cpp`)。1問につき1ファイル。両方あるときは `.cpp` を採点する。
- プログラムは標準入力から読み、標準出力に答えを書く。
- 採点環境:
  - C++ は `g++ -std=c++20 -O2` でコンパイルする。AtCoder Library などの外部ライブラリは使えない(標準ライブラリのみ)。
  - Python は CPython 3(PyPy ではない)で実行する。標準ライブラリのみ。
  - 実行時間制限は各問題文に書いてあるとおり(C++)。Python は CPython なので、その3倍まで認める。スタックの大きさの制限はない。
- 採点は、問題文にない多数のテストケース(最大サイズの入力を含む)で行う。
  1問の中で全テストケースに正解したときだけ、その問題を正解とする。
- 問題文の入出力例は、自分で確かめるのに使ってよい。

## 完了の条件

- 解けた問題の解答が `solutions/` に置いてある。
- 最後に、解答を置いた問題と、入出力例で確かめた結果を1行ずつ書く。
