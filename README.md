# GPT-6 Luna effort ベンチ(海外テックの「これマジ?」実験記録)

OpenAI の最安モデル **GPT-6 Luna** を Codex CLI で動かし、reasoning effort(low / medium / high / xhigh / max)を変えて、実務風の3課題と AtCoder の7問を解かせた記録です。YouTube チャンネル「海外テックの『これマジ?』」の動画のために行いました。

- 実行: 2026-09-24、Codex CLI 0.156.1、`gpt-6-luna`、39回(1本ずつ直列)
- 採点: すべて機械(隠しテスト・正解表)。費用は OpenAI の API 価格で換算した参考値(実際の実行は ChatGPT プランの枠で、請求は発生していません)
- 条件と経緯: [PRECHECK.md](PRECHECK.md)(事前に決めた判定・反証条件・隔離の方法・独立監査への対応)
- 結果: [RESULTS.md](RESULTS.md)(要約)/ [RESULTS_TABLE.md](RESULTS_TABLE.md)(全表)

## 結果の要約

**ふだんの仕事(各 effort 2回)**

| 課題 | low | medium | high | max |
|---|---|---|---|---|
| 機能追加(7群) | 7, 7 | 7, 7 | 7, 7 | 7, 7 |
| バグ修正(8群) | 7, 8 | 8, 7 | 8, 8 | 8, 8 |
| 決算資料の読解(16問) | 9, 9 | 16, 16 | 16, 16 | 16, 16 |

**AtCoder ABC476 A〜G(各 effort 3回)**

| effort | 平均正解数 | 1回の費用(API 換算) | 1回の時間 |
|---|---:|---:|---:|
| low | 3.0 | $0.0045 | 1.5分 |
| medium | 4.7 | $0.0055 | 2.0分 |
| high | 6.3 | $0.013 | 7.0分 |
| xhigh | 6.0 | $0.044 | 22.5分 |
| max | 6.7 | $0.053 | 24.9分 |

この課題では、high で max とほぼ同じ問題数を、費用約 1/4・時間約 1/3.5 で解きました。結果はこの課題に限ったもので、難問全般・ふだんの仕事全般には一般化していません。

## 中身

| パス | 内容 |
|---|---|
| `tasks/` | 課題文(日本語)。`base/` と `t2_bugfix/` は課題用の小さな家計簿ツール `ledgerlite`(バグ入り版を含む)。`t3_document/report.md` は架空企業の決算資料 |
| `tasks/t4_atcoder/` | 課題文のみ。**AtCoder の問題文は著作物のため同梱していません**(https://atcoder.jp/contests/abc476/tasks) |
| `hidden/` | 隠しテスト(T1・T2)、正解表(T3)、AtCoder のテストケース生成コードと生成済みケース(問題文の入出力例は除外)、T1 の参照実装 |
| `tools/` | 実行ハーネス(`run_trial.py`・`run_all.py`)、採点(`grade.py`・`grade_atcoder.py`)、集計(`summarize.py`)、この公開物の作成(`build_publish.py`) |
| `runs/<課題>/<effort>/r<n>/` | 各試行の記録(時間・リクエスト単位のトークン・費用・点数)、採点結果、実行したコマンドの一覧、最終メッセージ、最終成果物(`ws/`) |
| `sources/` | 料金の出典(OpenAI の各モデルのページ、2026-09-24 取得) |

公開していないもの: Codex の生ログとセッション記録(環境の情報を含むため。代わりに `commands.json` を置いています)、パイロット(較正)と無効にした試行、AtCoder の問題文と公式解説に由来する参照解。

## 再現するには

`tools/run_trial.py <課題> gpt-6-luna <effort> <回>`。作業フォルダ・Codex の設定フォルダのパスはコード内の定数を自分の環境に合わせてください。Codex の権限プロファイルで作業フォルダ以外の読み取りを禁止し、内蔵の Web 検索を無効にしています(パイロットで、Web 検索が有効なままだと公式解説を調べて解いてしまったため)。
